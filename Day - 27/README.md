# Day 27 - Miles to Kilometers Converter 📏

## Project Overview
GUI application that converts miles to kilometers using Tkinter. Features a clean interface with input field, labels, and calculation button.

## What I Learned
- **Tkinter GUI**: Creating desktop applications with Python
- **Grid Layout**: Positioning widgets in a grid system
- **Event Handling**: Button clicks and user interactions
- **Widget Configuration**: Customizing labels, buttons, and entries
- **Type Conversion**: Handling user input and calculations

## Key Features
- Clean, user-friendly interface
- Real-time conversion calculation
- Input validation through float conversion
- Responsive grid layout
- Window sizing and padding

## How to Run
```bash
python miles_to_km.py
```

## Technical Concepts
- Tkinter window creation and configuration
- Widget placement using grid geometry manager
- Event-driven programming with command callbacks
- Dynamic label text updates
- Entry widget for user input

## GUI Components
- **Entry**: Miles input field
- **Labels**: Static text and dynamic result display
- **Button**: Triggers conversion calculation
- **Grid Layout**: Organized 3x3 widget arrangement
