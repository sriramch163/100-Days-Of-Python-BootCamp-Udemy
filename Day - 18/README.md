# Day 18 - Hirst Spot Painting

## 🎨 Project Overview
A turtle graphics program that creates a colorful dot painting inspired by Damien Hirst's spot paintings. The program extracts colors from an image and creates a 10x10 grid of randomly colored dots.

## 🎯 Concepts Learned
- Turtle Graphics module
- Color extraction from images
- RGB color modes
- External library integration (colorgram)
- Grid-based drawing patterns

## 🚀 How to Run

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Add an image file named `1.jpg` to the project folder

3. Run the program:
```bash
python main.py
```

4. Click anywhere on the screen to exit

## 📋 Requirements
- Python 3.x
- colorgram.py library
- Image file (`1.jpg`)

## 🎨 Features
- Extracts 6 dominant colors from input image
- Creates 100 dots in a 10x10 grid
- Random color selection for each dot
- Black background for contrast
- Interactive exit (click to close)

- `main.py` - Main program file
