# Day 56 - Personal Portfolio Website with Flask

## 🎯 Project Overview
A personal portfolio website built with Flask framework, featuring a responsive design and professional layout.

## 🚀 Features
- **Flask Web Framework**: Server-side rendering with Python
- **Responsive Design**: Mobile-friendly HTML5 UP template
- **Professional Layout**: Clean, modern portfolio presentation
- **Static Assets**: CSS, JavaScript, and image resources
- **Social Links**: LinkedIn, GitHub, and portfolio integration

## 🛠️ Technologies Used
- **Backend**: Flask (Python web framework)
- **Frontend**: HTML5, CSS3, JavaScript
- **Template Engine**: Jinja2 (Flask's default)
- **Design**: HTML5 UP Identity template

## 📁 Project Structure
```
Day - 56/
├── server.py              # Main Flask application
├── requirements.txt       # Python dependencies
├── templates/
│   └── index.html        # Main portfolio template
└── static/
    ├── assets/           # CSS, JS, fonts
    └── images/           # Profile and background images
```

## 🔧 Installation & Setup

1. **Install Dependencies**:
```bash
pip install -r requirements.txt
```

2. **Run the Application**:
```bash
python server.py
```

3. **Access the Website**:
   - Open browser and navigate to `http://127.0.0.1:5000`

## 💡 Key Concepts Learned
- **Flask Framework**: Web application development
- **Template Rendering**: Using Jinja2 templates
- **Static File Serving**: CSS, JS, and image handling
- **Web Development**: Full-stack application structure
- **Responsive Design**: Mobile-first web development

## 🎨 Customization
- Update personal information in `templates/index.html`
- Replace profile image in `static/images/`
- Modify social media links in the footer section
- Customize styling in `static/assets/css/main.css`
