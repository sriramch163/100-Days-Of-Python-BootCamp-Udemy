# Day 11 - Blackjack Capstone Project 🃏

## Project Overview
A complete Blackjack game implementation featuring card dealing, scoring, and game logic with visual card symbols.

## Features
- Interactive Blackjack gameplay
- Card symbols (♠ ♥ ♦ ♣) for visual appeal
- Proper Blackjack scoring rules
- Ace handling (11 or 1)
- Computer dealer AI
- Multiple game rounds
- ASCII art logo

## How to Play
1. Run the program
2. Type 'y' to start a new game or 'n' to exit
3. Try to get as close to 21 as possible without going over
4. Type 'y' to draw another card or 'n' to pass
5. Beat the dealer to win!

## Game Rules
- Cards 2-10 = Face value
- Jack, Queen, King = 10 points
- Ace = 11 or 1 (automatically adjusted)
- Blackjack = 21 with 2 cards
- Dealer draws until 17 or higher

## Concepts Learned
- Functions with parameters and return values
- While loops and game flow control
- List manipulation
- Conditional logic
- Random module usage
- String formatting
- Modular programming
