# Day 75 - Google Trends Data Analysis with Python

## 📊 Project Overview
Analyze Google Trends data to uncover search patterns, seasonal trends, and correlations between different search terms using Python data science libraries.

## 🎯 Learning Objectives
- Work with Google Trends API and data
- Perform time series analysis
- Create correlation analysis between search terms
- Build interactive data visualizations
- Extract insights from search trend data

## 🛠️ Technologies Used
- **Python 3.x**
- **Pandas** - Data manipulation and analysis
- **Matplotlib/Plotly** - Data visualization
- **NumPy** - Numerical computations
- **pytrends** - Google Trends API wrapper
- **Seaborn** - Statistical data visualization

## 📋 Key Concepts Covered
- Google Trends API integration
- Time series data analysis
- Correlation analysis
- Seasonal trend detection
- Interactive plotting
- Data preprocessing and cleaning

## 🚀 How to Run
```bash
cd "Day - 75"
pip install pytrends pandas matplotlib plotly
python main.py
```
