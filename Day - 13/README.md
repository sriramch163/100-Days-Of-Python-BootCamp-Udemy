# Day 13 - Debugging 🐛

## Project Overview
A debugging practice day focused on identifying and fixing common Python programming errors through hands-on exercises.

## Learning Objectives
- Identify common Python bugs and errors
- Practice systematic debugging techniques
- Understand error messages and stack traces
- Learn debugging best practices
- Fix logical and syntax errors

## Files Structure
```
Day - 13/
├── debug/
│   ├── debug.py - Buggy code to fix
│   └── math.py - Helper module
└── code/
    ├── code.py - Fixed/working code
    └── math.py - Helper module
```

## Common Bug Types Covered
- **Logic Errors**: Incorrect program flow
- **Syntax Errors**: Invalid Python syntax
- **Runtime Errors**: Errors during execution
- **Import Errors**: Module import issues
- **Function Errors**: Parameter and return issues

## Debugging Techniques Learned
1. **Read Error Messages**: Understanding stack traces
2. **Print Debugging**: Adding print statements
3. **Code Review**: Line-by-line analysis
4. **Test with Simple Inputs**: Isolating problems
5. **Check Indentation**: Python-specific issues

## Key Concepts
- Error types and handling
- Stack trace interpretation
- Systematic problem-solving approach
- Code testing and validation
- Best practices for bug prevention

## Debugging Process
1. **Reproduce the Bug**: Understand when it occurs
2. **Read the Error**: Analyze error messages
3. **Isolate the Problem**: Narrow down the issue
4. **Fix and Test**: Implement solution and verify
5. **Prevent Future Bugs**: Apply best practices

## Usage
```bash
# Run buggy code to see bug
python debug/debug.py

# Run fixed code to see correct output
python code/code.py
```
