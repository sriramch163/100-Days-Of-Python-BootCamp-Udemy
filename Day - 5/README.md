# Day 5 - Password Generator

## Project Overview
A customizable password generator that creates secure passwords with user-specified character counts.

## What I Learned
- `for` loops and `range()` function
- `random.choice()` for selecting random elements
- `random.shuffle()` for randomizing lists
- List operations and string concatenation
- User input validation with `int()`

## How to Use
1. Run `Password-Generator.py`
2. Enter desired number of:
   - Letters (a-z, A-Z)
   - Symbols (!, #, $, %, etc.)
   - Numbers (0-9)
3. Get a randomized secure password

## Features
- **Easy Level**: Sequential character placement
- **Hard Level**: Shuffled character order for better security
- Customizable password length and composition

## Key Concepts
- **Loops**: Using `for` loops with `range()` for repetition
- **Random Selection**: `random.choice()` from predefined lists
- **List Shuffling**: `random.shuffle()` for password randomization
- **String Building**: Concatenating characters into final password
