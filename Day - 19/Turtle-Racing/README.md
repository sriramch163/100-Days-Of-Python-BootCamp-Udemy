# Turtle Racing Game 🐢🏁

An exciting turtle racing game where you bet on which colored turtle will win the race!

## 🎮 How to Play

1. **Place Your Bet**: Choose from available turtle colors
2. **Watch the Race**: Six turtles race to the finish line
3. **See Results**: Find out if your turtle won!

## 🌈 Available Turtles

- 🔴 Red Turtle
- 🟠 Orange Turtle  
- ⚪ White Turtle
- 🩷 Pink Turtle
- 🔵 Blue Turtle
- 🟢 Green Turtle

## 🚀 Features

- Interactive betting system with color selection
- Random race outcomes for unpredictability
- Visual race display with colored turtles
- Automatic win/loss detection
- 3-second result display before auto-close

## 🛠️ Technical Implementation

- **Random Movement**: Each turtle moves 10-20 steps randomly per turn
- **Race Logic**: First turtle to cross y-coordinate 360 wins
- **User Input**: Text input dialog for betting
- **Visual Feedback**: Clear win/loss messages with emojis
- **Auto-Exit**: Closes automatically after showing results

## 📚 Concepts Learned

- Turtle graphics and animation
- Random number generation
- List iteration and management
- User input handling
- Conditional logic and game states
- Screen setup and coordinate systems

## 🎯 Usage

```bash
python main.py
```

Enter your color choice when prompted and watch the race!
