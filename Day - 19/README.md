# Day 19 - Event Handling & Turtle Graphics 🐢

**Focus**: Advanced event handling, user input, and interactive graphics programming

## 📁 Projects Overview

This day features two interactive projects that demonstrate event handling and user interaction:

### 1. 🎨 [Etch-A-Sketch App](./Etch-A-Sketch-App/)
Digital recreation of the classic drawing toy with smooth keyboard controls.

**Key Features:**
- WASD movement controls
- Continuous drawing
- Screen clearing functionality
- Real-time event handling

### 2. 🏁 [Turtle Racing Game](./Turtle-Racing/)
Interactive betting game where users predict the winning turtle.

**Key Features:**
- User betting system
- Random race mechanics
- Visual race display
- Win/loss feedback

## 🎯 Learning Objectives

- **Event Handling**: Key press/release detection and response
- **User Input**: Text input dialogs and validation
- **State Management**: Global variables and flags
- **Animation**: Timer-based continuous movement
- **Game Logic**: Race conditions and winner detection
- **Screen Management**: Setup, clearing, and coordinate systems

## 🛠️ Technical Concepts

### Event Handling Methods
- `onkeypress()` - Detect key press events
- `onkeyrelease()` - Detect key release events  
- `onkey()` - Single key press detection
- `textinput()` - User text input dialogs

### Animation Techniques
- Timer-based loops with `ontimer()`
- Continuous movement with state flags
- Real-time screen updates

### Turtle Graphics Advanced
- Multiple turtle instances
- Color and shape customization
- Coordinate positioning
- Screen setup and configuration

## 🚀 How to Run

Navigate to each project folder and run:
```bash
python main.py
```

## 📚 Skills Developed

- Interactive application design
- Event-driven programming
- User experience considerations
- Game mechanics implementation
- Visual feedback systems
