# Day 14 - Higher Lower Game (Anime Edition) ⚔️

## Project Overview
An anime-themed Higher Lower guessing game where players compare power levels of different anime characters.

## What I Learned
- **Functions with Multiple Parameters**: Creating reusable functions that take multiple inputs
- **Data Manipulation**: Working with dictionaries and lists of complex data
- **Game Logic**: Implementing comparison logic and score tracking
- **Code Organization**: Separating data, art, and main game logic into different files
- **Random Selection**: Using random.choice() for game mechanics
- **String Formatting**: Creating formatted output for better user experience

## How It Works
1. Game displays two random anime characters
2. Player guesses which character has higher power level
3. Correct guesses increase score and continue the game
4. Wrong guess ends the game and shows final score

## Key Features
- 70+ anime characters with power levels
- Emoji-rich interface for better visual appeal
- Score tracking system
- Prevents duplicate character comparisons
- Clear screen functionality for better gameplay

## Files Structure
- `Higher-Lower.py` - Main game logic
- `game_data.py` - Character data with power levels
- `art.py` - ASCII art for logo and VS symbol
