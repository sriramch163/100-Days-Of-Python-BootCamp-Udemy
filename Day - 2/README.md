# Day 2 - Tip Calculator 💰

## Description
A Python program that calculates how much each person should pay when splitting a bill with tip.

## How it Works
The program asks for:
1. Total bill amount
2. Tip percentage (10%, 12%, or 15%)
3. Number of people splitting the bill

It calculates the total amount including tip and divides it equally among all people.

## Usage
```bash
python Tip_Caluculator.py
```

```
How much tip would you like to give? 10, 12 or 15? 12

```
