# Day 1 - Band Name Generator 🎶

## Description
A simple Python program that generates a band name by combining the user's hometown and pet name.

## How it Works
The program prompts the user for:
1. The city they grew up in
2. The name of a pet

It then combines these inputs to create a unique band name.

## Usage
Run the program:
```bash
python Band_Name_Generator.py
```

## Example Output
```
Welcome to the Band Name Generator🎶
Which city did you grow up in?
 New York
What is the name of a Pet?
 Buddy
Your Band name could be: New York Buddy
```
