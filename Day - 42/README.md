## HTML Elements Used
- `<h1>, <h2>, <h3>` - Heading hierarchy for content structure
- `<img>` - Image element with src, alt, and width attributes
- `<ul>` - Unordered list container
- `<li>` - List items for organized content
- `<a>` - Anchor tag for external links with target attribute

## New HTML Concepts

### 1. Image Element
```html
<img src="image-file.jpg" alt="Description" width="600">
```
- **src**: Path to image file
- **alt**: Alternative text for accessibility
- **width**: Image width in pixels

### 2. Unordered Lists
```html
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ul>
```

### 3. External Links
```html
<a href="https://example.com" target="_blank">Link Text</a>
```
- **href**: URL destination
- **target="_blank"**: Opens in new tab
