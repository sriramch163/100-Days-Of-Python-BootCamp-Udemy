# Day 3 - Treasure Hunt Game

## Project Overview
A text-based adventure game where players navigate through choices to find treasure.

## What I Learned
- Conditional statements (`if`, `elif`, `else`)
- Nested conditionals
- String methods (`.lower()`)
- User input handling
- ASCII art integration

## How to Play
1. Run `Treasure-Hunt.py`
2. Make choices at each crossroad:
   - **Crossroad**: Choose "left" or "right"
   - **Lake**: Choose "wait" or "swim" 
   - **Island**: Choose "red", "yellow", or "blue" door

## Winning Path
Left → Wait → Yellow door = Victory!

## Key Concepts
- **Conditional Logic**: Multiple decision points create different game outcomes
- **Input Validation**: Using `.lower()` for case-insensitive input
- **Nested Structure**: Decisions within decisions for complex game flow
