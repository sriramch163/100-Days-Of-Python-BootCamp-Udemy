# Day 4 - Rock Paper Scissors Game

## Project Overview
Classic Rock Paper Scissors game with ASCII art where you play against the computer.

## What I Learned
- `random` module and `random.randint()`
- Lists and indexing
- Multi-line strings with triple quotes
- Complex conditional logic
- Type conversion with `int()`

## How to Play
1. Run `Rock-Paper-Scissors.py`
2. Choose: 0 (Rock), 1 (Paper), or 2 (Scissors)
3. Computer makes random choice
4. Winner determined by classic rules

## Game Rules
- Rock beats Scissors
- Paper beats Rock  
- Scissors beats Paper
- Same choice = Tie

## Key Concepts
- **Random Generation**: Using `random.randint()` for computer moves
- **List Indexing**: Accessing ASCII art by index
- **Game Logic**: Multiple conditions to determine winner
