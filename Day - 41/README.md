# Day 41 - Introduction to HTML 🌐

## Project Overview
First step into web development with HTML basics. Created a personal website using fundamental HTML elements including headings, paragraphs, line breaks, and horizontal rules.

## What I Learned
- **HTML Structure**: Basic HTML document structure with DOCTYPE, html, head, and body tags
- **Headings**: Using h1, h2, h3 tags for content hierarchy
- **Paragraphs**: Creating text content with p tags
- **Text Formatting**: Using strong tag for bold text
- **Line Breaks**: br tag for line breaks within content
- **Horizontal Rules**: hr tag for visual separation
- **Semantic HTML**: Proper use of heading levels and structure
- **Meta Tags**: Setting character encoding and viewport for responsiveness

## Key Features
- **Personal Website**: Simple personal introduction page
- **Proper Structure**: Well-organized HTML document
- **Text Formatting**: Bold text for emphasis
- **Visual Separation**: Horizontal rules for content sections
- **Contact Information**: Structured contact details

## HTML Elements Used
- `<!DOCTYPE html>` - HTML5 document type declaration
- `<html>` - Root element with language attribute
- `<head>` - Document metadata container
- `<meta>` - Character encoding and viewport settings
- `<title>` - Page title displayed in browser tab
- `<body>` - Main content container
- `<h1>, <h2>, <h3>` - Heading hierarchy
- `<p>` - Paragraphs for text content
- `<strong>` - Bold/important text
- `<br>` - Line breaks
- `<hr>` - Horizontal rules for visual separation

## Page Structure

3. **Contact Section**: Email and location information
