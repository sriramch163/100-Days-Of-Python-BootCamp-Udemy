# Day 25 - U.S. States Game 🗺️

## Project Overview
Interactive geography game where players guess U.S. state names. Correctly guessed states appear on a map, and missed states are saved to a CSV file for study.

## What I Learned
- **Pandas Library**: Data manipulation and CSV handling
- **Turtle Graphics**: Interactive GUI programming
- **Data Analysis**: Working with DataFrames and data filtering
- **File I/O**: Reading CSV files and creating new data files
- **Game Logic**: Score tracking and exit conditions

## Key Features
- Interactive map-based guessing game
- Real-time score tracking (X/50 states)
- State positioning using coordinate data
- Export missed states for review
- Clean exit functionality

## How to Run
```bash
python main.py
```

## Files
- `main.py` - Main game logic
- `50_states.csv` - State names and coordinates data
- `blank_states_img.gif` - U.S. map background image
- `states_you_missed.csv` - Generated file with unguessed states

## Game Instructions
1. Type state names when prompted
2. Correctly guessed states appear on the map
3. Type "exit" to end game and save missed states
4. Try to guess all 50 states!

## Technical Concepts
- Pandas DataFrame operations
- Turtle screen and shape management
- Event-driven programming
- Data filtering and list comprehensions
- CSV file generation
