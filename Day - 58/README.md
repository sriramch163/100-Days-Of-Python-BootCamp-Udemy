# Day 58 - TinDog Bootstrap Website 🐕

## Project Overview
A responsive dog dating website built with HTML, CSS, and Bootstrap 5. This project demonstrates modern web development techniques using Bootstrap's grid system, components, and responsive design principles.

## 🎯 Learning Objectives
- Bootstrap 5 framework implementation
- Responsive web design
- CSS animations and gradients
- Bootstrap components (cards, buttons, grid system)
- Modern web layout techniques

## 🛠️ Technologies Used
- **HTML5**: Semantic markup and structure
- **CSS3**: Custom styling and animations
- **Bootstrap 5.3.0**: Responsive framework
- **Bootstrap Icons**: Icon library

## 🚀 How to Run
1. Open `solution.html` in any modern web browser
2. Or serve locally using Python:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`

## ✨ Features
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Animated Background**: CSS gradient animation
- **Bootstrap Components**: Cards, buttons, grid system
- **Modern Layout**: Hero section, features, testimonials, pricing
- **Professional Styling**: Clean, modern design

## 🎨 Key CSS Features
- Gradient background animation
- Responsive image handling
- Bootstrap icon integration
- Custom styling over Bootstrap defaults

## 📱 Responsive Breakpoints
- Mobile: < 576px
- Tablet: 576px - 992px
- Desktop: > 992px

## 🔗 External Dependencies

- Bootstrap Icons (CDN)
